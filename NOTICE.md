## Government open data

HawkerBridge uses data from the National Environment Agency (NEA), Singapore Department of Statistics (SingStat), and Urban Redevelopment Authority (URA), made available on data.gov.sg under the [Singapore Open Data Licence](https://data.gov.sg/open-data-licence). HawkerBridge is an independent challenge project and is not endorsed by those agencies.

The machine-readable source catalogue (`data/sources.json`) identifies each dataset. Each raw bundle includes original source bytes and provenance/checksums. The delivered baseline uses official endpoints. Optional explicitly requested mirror acquisition retains the real transport URL and marks mirror status; it never misrepresents a mirror as a direct agency download.

## Software and fonts

React, Vite, TypeScript, FastAPI, Uvicorn, NumPy, SciPy, HiGHS, Shapely, ReportLab, Argon2, Databricks SDK, Leaflet, Lucide, Vitest, pytest, Playwright and axe-core retain their respective open-source licenses. Their package license files are distributed in installed dependencies; no external font or map request is required for the app.

Illustrative product artwork is original SVG code. It is not a photograph of a real venue. Any browser evidence shows the implemented application using the documented source snapshot and scenario assumptions.
